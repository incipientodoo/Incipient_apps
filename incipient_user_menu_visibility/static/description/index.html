INTERFACE SHOWCASE

Step-by-Step Visual Walkthrough

How Per-User Menu Visibility Control operates in Odoo

Step 01

Navigate to Users & Companies

As an Administrator, open the Command Palette (CTRL + K) or navigate through Odoo settings to access Settings → Users & Companies → Users.

Quickly locate and open the user profile whose menu access permissions you want to customize.

Step 02

Select Target User Record

Open the target user's form view (e.g., Test Menu User) and verify their assigned standard roles and access groups.

Notice the dedicated Menu Visibility notebook tab added to the user form for granular menu management.

Step 03

Select Menus to Hide

Switch to the Menu Visibility tab and click Add a line under the Hidden Menus list.

A popup dynamically displays only the menus currently accessible to this specific user according to their assigned security groups.

Step 04

Save Menu Restrictions

Review the selected hidden menus (such as Discuss → Configuration) showing menu name, parent menu, and action details.

Save the record. The module automatically flushes the cache to enforce visibility restrictions immediately.

Step 05

Hidden Menu Enforced in User Session

When the restricted user logs in, the chosen menu and all its child sub-menus are completely excluded from the navigation bar.

As shown, the Configuration menu is completely suppressed from Discuss navigation for this user.

Step 06

Remove Restriction / Restore Menu

To restore access at any time, simply delete the entry from the Hidden Menus list in the user profile.

Alternatively, if the user type is changed to Portal/Public, restrictions are automatically cleared.

Step 07

Restored Menu Immediately Visible

Upon saving and refreshing the user session, the previously hidden menu (e.g., Configuration) instantly reappears.

Provides full lifecycle menu control without touching or altering core security group definitions.

Frequently Asked Questions

Click any question below to expand or collapse details

1. Is Per-User Menu Visibility Control compatible with Odoo Enterprise, Community, and Odoo.sh?
Yes! The module is 100% compatible with Odoo Community Edition, Enterprise Edition, and Odoo.sh cloud deployments without altering core source code.
2. Does hiding a parent menu automatically hide its child sub-menus?
Yes. When any parent menu is selected as hidden, our recursive resolution automatically traverses down the menu tree and excludes all descendant sub-menus and actions.
3. What happens if a user is converted to Portal or Public user?
Whenever an internal user loses internal-user access (`base.group_user`), any configured menu restrictions on that record are automatically cleared to avoid stale access rules.
4. Can non-admin users edit their own hidden menus?
No. The "Menu Visibility" tab is strictly restricted to Administration / Access Rights managers (`base.group_erp_manager`). Regular users cannot see or modify this tab.
5. Are hidden menus only removed from the top bar or also from the Command Palette (CTRL + K)?
They are completely blacklisted from the web client's menu payload (`load_menus`), which removes them from both top navigation bars and search command palettes (CTRL + K).
6. Does this module require installing third-party Python packages?
None at all. It is built strictly using standard native Odoo ORM methods, requiring zero external Python libraries or third-party binaries.
7. Does hiding menus affect other users in the same security group?
No. Restrictions are bound exclusively to the specific user record (`res.users`). Other team members in the same security groups continue to see their regular menus normally.
8. Does the purchase include free lifetime updates for future Odoo releases?
Yes. Every purchase from Incipient Corp includes lifetime free updates and bug fixes for the purchased major release line.
9. Can hidden menus be restored at any time?
Yes. Administrators can remove entries from the Hidden Menus list on the user form at any time, instantly restoring full menu visibility.
