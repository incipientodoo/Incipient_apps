1. Is GUID Synchronization compatible with Odoo Enterprise, Community, and Odoo.sh?
Yes! GUID Synchronization is 100% compatible with Odoo Community Edition, Enterprise Edition, and Odoo.sh cloud deployments without modifying core files.
2. How does GUID tracking work in a multi-company setup?
The module fully respects Odoo's standard multi-company security rules. GUID tracking logic remains isolated per operating entity, preventing cross-company data leakage while ensuring accurate internal tracking.
3. Which Odoo models are supported out of the box?
GUID Synchronization natively supports major core models including Sales Orders, Purchase Orders, Customer Invoices, Vendor Bills, Journal Items, and CRM Leads/Opportunities.
4. How are the Global Unique Identifiers (GUIDs) generated?
GUIDs are generated using robust, industry-standard cryptographic algorithms at the exact moment a record is created. This guarantees absolute uniqueness and eliminates the possibility of ID collisions.
5. Does this module impact database performance on large datasets?
No. The module utilizes highly optimized database indexing on the GUID fields. Searching and tracking remain lightning-fast, even on enterprise databases containing millions of records.
6. Does this module require installing third-party Python packages?
None at all. It is a clean, native Odoo app that installs in seconds without installing external Python dependencies.
7. How does GUID Synchronization prevent duplicate data entry?
The module enforces strict database-level uniqueness constraints on the generated GUIDs. This prevents both users and external API integrations from accidentally creating duplicate records.

9. Can I export GUID data to Excel or external systems?
Yes. GUIDs are available as standard fields that can be easily exported to Excel or retrieved via XML-RPC/REST APIs to synchronize perfectly with your external ERPs or reporting tools.
