INTERFACE SHOWCASE

Step-by-Step Visual Walkthrough

How View-Only Observer Roles operate seamlessly in Odoo 19

Step 01

User Security Group Assignment

Navigate to Settings → Users & Companies → Users to assign specialized read-only observer permissions.

Under the user profile's Access Rights, configure dedicated Incipient Observer Roles: select Sales Observer (Read-Only) or Purchase Observer (Read-Only) to grant audit visibility without standard write privileges.

Step 02

Sales Observer Profile Configuration

Inspect and confirm the access rights setup for the dedicated Sales Observer user profile.

Standard Sales write/admin permissions are set to None, while Sales Observer (Read-Only) is enabled, granting viewing access to quotations, sales orders, linked deliveries, customer invoices, and BOMs.

Step 03

Purchase Observer Profile Configuration

Inspect and verify the security group configuration for the procurement auditor user profile.

Standard Purchase user permissions are left unselected, while Purchase Observer (Read-Only) is activated, allowing audit oversight of RFQs, purchase orders, receipts, vendor bills, and related manufacturing BOMs.

Step 04

Strict Access Error Enforcement on Unauthorized Actions

Backend ORM access rules strictly prevent unauthorized write, edit, or delete operations.

If an observer attempts to modify an existing order or perform restricted administrative operations, Odoo immediately raises an AccessError dialog, preventing any data manipulation or security breaches.

Step 05

Sales Order Read-Only Verification

Logged in as the Sales Observer user, open sales orders (e.g., Quotations / Orders) in full read-only mode.

Customer information, order lines, unit pricing, taxes, and smart buttons are fully readable. Action buttons and "New" buttons are automatically suppressed so fields cannot be modified.

Step 06

Purchase Order Modification Block & Access Warning

Strict record-level security safeguards ensure purchase transactions cannot be altered.

Any attempt by a Purchase Observer to confirm, edit order lines, update unit prices, or delete a purchase order is instantly blocked with a security warning, maintaining complete audit integrity.

Step 07

Purchase Order Read-Only Audit Oversight

View complete procurement orders with full audit clarity across vendors, products, and order totals.

Auditors can inspect vendor details, scheduled delivery dates, purchase order line totals, and linked receipts/vendor bills without any ability to alter or create records.

Frequently Asked Questions

Click any question below to expand or collapse details

1. What is the primary purpose of Incipient View-Only Observer Roles?
The module provides dedicated, secure, read-only security roles (Sales Observer and Purchase Observer) for auditors, management, financial controllers, and third-party reviewers to audit transactions without having create, edit, or delete permissions.
2. Can a Sales Observer or Purchase Observer edit order lines or confirm orders?
No. All edit, create, confirm, and delete operations are strictly blocked at both the user interface level (suppressed action/new buttons) and the backend ORM security layer via ir.rule and ir.model.access.csv access controls with an AccessError.
3. Which related records can an observer user view?
Observers have full read visibility into orders (sale.order / purchase.order), order lines, linked inventory receipts and delivery pickings (stock.picking, stock.move, stock.move.line), customer invoices and vendor bills (account.move, account.move.line), and manufacturing Bills of Materials (mrp.bom, mrp.bom.line).
4. How do I assign the observer role to an auditor user?
Log in as an Administrator, navigate to Settings → Users & Companies → Users, select the auditor user, open the Access Rights tab, locate the Incipient Observer Roles section, and select either "Sales Observer (Read-Only)" or "Purchase Observer (Read-Only)".
5. Are Sales Observer and Purchase Observer independent roles?
Yes. They are separate groups created using Odoo 19 privileges (res.groups.privilege). You can assign only Sales Observer, only Purchase Observer, or both to the same auditor user depending on organizational audit requirements.
6. Is this module compatible with Odoo Enterprise, Community, and Odoo.sh?
Yes! The module is 100% compatible with Odoo 19 Community Edition, Enterprise Edition, and Odoo.sh cloud environments without altering standard core source code.
7. Does the module require installing external third-party Python libraries?
None at all. It is built strictly on standard Odoo XML security definitions, privileges, and access CSV files, ensuring fast and seamless installation with zero external dependencies.
8. How does multi-company security work for observer users?
Observer users respect standard Odoo multi-company record rules. Observers can only view orders and records belonging to the company or companies they have been assigned access to by the administrator.
9. Can observer users view sales spreadsheets and analytical reports?
Yes. The Sales Observer role includes model access to sale.order.spreadsheet, enabling auditors to view sales analytical spreadsheets and report templates in read-only mode.
