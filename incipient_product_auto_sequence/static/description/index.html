INTERFACE SHOWCASE

Step-by-Step Visual Walkthrough

How Category-Based Product Auto-Sequencing operates in Odoo

Step 01

Access Product Categories Menu

Use the command palette or navigate to Invoicing → Configuration → Invoicing → Product Categories (or via Inventory → Configuration → Products → Categories).

Quickly locate and open your product categories list to configure auto-sequencing rules.

Step 02

Configure Category Sequence (Electronics)

Open a category such as Electronics. Under the dedicated Internal Reference Auto-Sequencing group, enable the Auto-Sequence Internal Ref toggle.

Define a custom prefix like ELEC-. The system automatically creates and links the sequence: Internal Reference Sequence - Electronics.

Step 03

Configure Second Category (Toys)

Open another category such as Toys and enable Auto-Sequence Internal Ref.

Set the sequence prefix to TOY-. An isolated sequence Internal Reference Sequence - Toys is automatically generated and linked.

Step 04

Inspect & Fine-Tune Sequence Rules

Click into the generated sequence record to inspect sequence code (product.category.auto.sequence), prefix (TOY-), sequence size/padding (5), and next counter values.

Leverages standard Odoo ir.sequence flexibility with zero custom configuration overhead.

Step 05

Automatic SKU Assignment on Product Creation

Create a new product like Toy Product under the Toys category and save.

The system automatically assigns the next sequence number (TOY-00001) to the Reference field without any manual typing.

Step 06

Manual Reference Override Support

Create a second product, such as Toy Product - 2, and enter a custom internal reference (e.g. TOY-SKU-2).

The module respects user input and does not overwrite custom manual codes, ensuring maximum operational flexibility.

Step 07

Category with Custom Prefix (Home Construction)

Set up another category, such as Home Construction, with sequence prefix HOME_CONST -.

Supports alphanumeric prefixes, dashes, underscores, and spacing to match your enterprise naming convention.

Step 08

Independent Sequential Reference Generation

Create Home Product under Home Construction and save the product.

The product immediately receives reference HOME_CONST -00001, demonstrating perfectly isolated sequence tracking across different product categories.

Frequently Asked Questions

Click any question below to expand or collapse details

1. Is Category-Based Product Auto-Sequencing compatible with Odoo Enterprise, Community, and Odoo.sh?
Yes! The module is 100% compatible with Odoo 19.0 Community Edition, Enterprise Edition, and Odoo.sh cloud deployments without altering core models.
2. How does the module generate sequence numbers for each category?
When you enable "Auto-Sequence Internal Ref" on a category, the system automatically creates a dedicated ir.sequence record. You can specify a custom prefix (e.g. ELEC-) or let it generate one from the first 3 letters of the category name.
3. What happens if I manually enter an Internal Reference when creating a product?
If you provide a manual Internal Reference, the module respects your entry and does not overwrite it with an automated sequence number.
4. What happens when I change an existing product's category?
If the product is reassigned to another category with auto-sequencing enabled, the system automatically draws a new reference from the target category's sequence engine.
5. Are product variants supported?
Yes. Product variants automatically inherit the template's auto-generated internal reference, and variants created directly under auto-sequenced categories also receive unique references.
6. Can I customize the padding and prefix of each sequence?
Yes. You can edit the prefix directly from the Category form, or click on the linked sequence to customize padding length, prefix, suffix, and next counter values in standard Odoo Sequence management.
7. Does this affect existing products created before installation?
Existing products keep their existing internal references intact. They are only assigned new numbers if their category is actively changed to an auto-sequenced category.
8. Does this module impact database performance on bulk product creation or import?
No. The module leverages native multi-create (create_multi) and standard PostgreSQL sequences, ensuring optimal batch speed with zero lag during bulk imports.
9. Does the module require installing external Python packages?
No external Python packages or system binaries are required. It installs cleanly and instantly using standard Odoo framework dependencies.
